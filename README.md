PhysicalLink AI 🤖

AI-Powered Physical Robot Planning and Digital Twin Simulation

📌 About the Project

PhysicalLink AI is an AI-powered robot planning system that uses NVIDIA NeMoTron to understand tasks, plan actions, and simulate robot movement in a 2D digital twin environment. It aims to help robots identify obstacles, explore safe paths, and improve decisions before performing physical actions.

🎯 Problem Statement

Physical robots can face obstacles and unexpected situations while performing tasks. Testing every action directly on a real robot can be time-consuming and costly. PhysicalLink AI aims to provide a digital simulation environment where robot movement and path planning can be explored before real-world execution.

💡 Our Solution

PhysicalLink AI combines AI-based task understanding, robot path planning, and 2D digital twin simulation to demonstrate how a robot can plan its movement and avoid obstacles in a virtual environment.

✨ Key Features

- AI-assisted task understanding and planning.
- 2D digital twin environment for robot movement simulation.
- Obstacle-aware route planning.
- Visual representation of the robot's movement.
- Simulation-based testing before real-world execution.
- Experience memory to support learning from previous simulations, where implemented.

🚀 Getting Started

Prerequisites

- Python installed
- Node.js and npm installed
- Git installed

1. Clone the Repository

git clone https://github.com/roopa-n-gfi/PhysicalLink-AI.git
cd PhysicalLink-AI

2. Start the Frontend

cd frontend
npm install
npm run dev

Open the local URL displayed in the terminal.

3. Start the Backend

Open a second terminal in the project root and follow the backend setup instructions. Activate the appropriate Python environment, install the project's required dependencies, and start the backend using the actual entry point and command configured in the project.
